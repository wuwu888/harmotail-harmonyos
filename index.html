HarmoTail

A production-focused Tailscale-compatible client for HarmonyOS NEXT.

HarmoTail brings native Tailscale connectivity to Huawei and HarmonyOS NEXT devices, with a focus on full mobile-client functionality, reliable system VPN integration, long-term compatibility, and a release-ready user experience.

Product coverage

Built beyond a proof of concept.

HarmoTail is designed as an end-user product, not only a platform port. The current build already covers major Tailscale mobile-client workflows.

Native VPN / TUN

HarmonyOS-native VPN integration backed by the open-source Tailscale core.

OAuth & Accounts

Interactive sign-in, multi-account switching, saved profiles, and auth-key login.

Devices

Tailnet device visibility with peer status, paths, activity, and node information.

Exit Nodes

Select and use approved Tailscale exit nodes with LAN-access controls.

DNS & MagicDNS

DNS preferences, effective resolvers, search domains, and Core DNS route visibility.

App Split Tunneling

HarmonyOS app-based routing using the platform VPN blocked-applications capability.

Taildrop

Native file transfer flows for sending and receiving through Tailscale.

Taildrive

Taildrive browsing and transfer workflows integrated into the native client experience.

Diagnostics

Tailscale Bug Report support, network diagnostics, and privacy-safe support reports.

Tailnet Lock

Read-only visibility into Tailnet Lock state, keys, authority state, and filtered peers.

Node Key Expiry

Displays Core-reported key expiry, remaining time, and re-authentication guidance.

Commercial UX

Product-oriented settings, status, recovery, safety gates, and upgrade-aware behavior.

Architecture

Native where it matters.

Partnership

Built to complement the Tailscale ecosystem.

HarmoTail does not aim to replace or compete with the Tailscale control plane. The goal is to provide a high-quality native HarmonyOS endpoint for users and organizations already relying on the Tailscale ecosystem.

Partnership interests: technology partnership, compatibility guidance, trademark and branding guidance, commercial distribution, enterprise deployment, and long-term upstream compatibility.
