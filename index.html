Made for HarmonyOS

原生连接，属于你的网络。

HarmoTail 是运行于 HarmonyOS 平台的原生网络客户端，帮助用户连接自己的 Tailscale 网络环境。

原生 HarmonyOS

面向 HarmonyOS 打造，从连接状态到设备管理，提供原生操作体验。

系统 VPN

接入 HarmonyOS 系统 VPN，在系统网络能力中管理连接。

本地优先

在设备端管理连接与偏好，让日常网络操作回到本机。

你自己的 Tailscale 网络

使用自己的 Tailscale 账户，连接和访问自己网络中的设备。

Features

日常连接所需，集中管理。

从登录、设备管理到文件传输，在 HarmonyOS 上使用自己的 Tailscale 网络。Beta 功能持续完善，具体可用状态以应用内提示为准。

  • ✓Tailscale 登录认证

    使用自己的 Tailscale 账户登录并连接网络。

  • ✓Peer 设备管理

    查看网络中的设备及其连接状态。

  • ✓Exit Node

    选择自己网络中可用的出口节点。

  • ✓Exit DNS

    查看出口连接相关的 DNS 设置与状态。

  • ✓Allow LAN

    局域网访问选项，Beta 阶段持续完善。

  • ✓Taildrop 文件传输

    在自己的设备之间发送和接收文件。

  • ✓多 Profile

    管理已保存的账户配置，按需切换。

  • ✓App 分流

    按应用设置分流，适应不同连接需求。
