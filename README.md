# HarmoTail - Tailscale for HarmonyOS / 鸿蒙

## HarmonyOS NEXT 原生 Tailscale 客户端

HarmoTail 是面向 HarmonyOS NEXT / 鸿蒙系统的原生 Tailscale 客户端。

如果你正在寻找 **Tailscale 鸿蒙客户端、HarmonyOS Tailscale、鸿蒙 VPN、HarmonyOS NEXT VPN**，
HarmoTail 可以让华为鸿蒙设备接入自己的 Tailscale Tailnet。

当前正式版本：**v0.16.1**

## 主要功能

### 网络连接

- 原生 HarmonyOS VPN 接入
- Tailscale 网络连接
- Tailnet / Peer 设备查看
- DNS 状态与设置
- Tailnet Lock 状态查看

### Exit Node

- Exit Node 支持
- Exit DNS
- Allow LAN 局域网访问
- 自动恢复最近使用的出口节点

### 设备互联

- Taildrop 文件传输
- Taildrive
- 多 Profile 管理
- App 应用分流

### 稳定性

- VPN 生命周期优化
- 网络恢复优化
- 连接状态自动恢复
- 技术支持报告
